# 文字起こし（Windows 11）

**この PC の中だけで**音声を文字にするソフト。話した内容も音声ファイルも外へ出さない
（モデルを最初に取ってくるときだけ通信する。それ以降は機内でも動く）。

| 入力 | 何を文字にするか |
|---|---|
| 🎤 **マイク** | いま話している声。区切りごとに次々出る |
| 🔊 **PC で鳴っている音** | 会議アプリ・動画・ブラウザの音（WASAPI ループバック。ステレオミキサーの設定は要らない） |
| 📄 **音声ファイル** | wav / mp3 / m4a / aac / flac / ogg / opus / wma など |
| 📄 **動画ファイル** | mp4 / mov / mkv / avi / webm / wmv など。**音声トラックだけを取り出して読む** |

書き出しは **txt / srt / vtt**。日本語のほか、英語への翻訳出力もできる。

---

## 入れる

1. **Python を入れる**（入っていなければ）
   ```
   winget install Python.Python.3.12
   ```
   python.org のインストーラを使う場合、**tcl/tk のチェックを外さない**（画面が出せなくなる）。

2. **`setup.bat` をダブルクリック**
   `.venv` を作り、必要なもの（faster-whisper / sounddevice / numpy）と `small` モデルを取ってくる。
   ここだけ通信が要る。5〜10 分ほど。

   細かく指定したいときは PowerShell から:
   | やりたいこと | コマンド |
   |---|---|
   | 大きいモデルを取っておく | `.\setup.ps1 -Model large-v3-turbo` |
   | モデルは後で（起動時に取りに行く） | `.\setup.ps1 -NoModel` |
   | NVIDIA GPU で動かす | `.\setup.ps1 -Gpu` |

3. **`run.bat` をダブルクリック**して起動。ショートカットをデスクトップに置いておくとよい。

## 使う

### 話しながら文字にする

1. 上段の **入力** で `マイク: …` を選ぶ（`⟳` で一覧を取り直す）
2. **● 録音を開始**（`Ctrl+R`）
3. 話す。**話の切れ目**ごとに 1 行ずつ確定していく
   琥珀色の `… ` の行は**まだ確定していない途中経過**で、確定すると差し替わる
4. **■ 停止**で終わり。最後まで言い切った分も書き出される

### 会議や動画の音を文字にする

入力で **`PC音声: …（この PC で鳴っている音）`** を選んでから開始する。
スピーカーから出ている音をそのまま拾うので、**イヤホンでも拾える**（マイクを経由しない）。

> 自分の声も一緒に残したいときは、Windows の設定でマイクを「聞く」ようにするか、
> 会議アプリ側の録音機能を使うこと。このソフトは一度に 1 つの入力しか開かない。

### ファイルを文字にする

**ファイルを開く**（`Ctrl+O`）で音声・動画を選ぶ。**複数選ぶと順に処理する**。
`run.bat` に**ファイルを放り込む**（ドラッグ＆ドロップ）だけでも同じ。

## 画面の設定

| 項目 | 意味 |
|---|---|
| **モデル** | 大きいほど正確、そのぶん遅い（下の表） |
| **言語** | `日本語` を選んでおくと安定する。`自動判定` は短い発話で外すことがある |
| **出力** | `文字起こし`（話した言語のまま）か `英語に翻訳` |
| **処理** | `自動` / `CPU` / `GPU (CUDA)`。GPU で開けなければ黙って CPU に落ちる |
| **途中経過** | 確定前の文字を薄く出す。CPU が苦しいときは外す |
| **時刻** | 各行の頭に録音開始からの時刻を付ける |
| **自動保存** | 1 行確定するたびに `ドキュメント\文字起こし\` の txt へ書き足す（落ちても残る） |

`Ctrl+R` 録音の開始/停止 ・ `Ctrl+O` ファイル ・ `Ctrl+S` 保存

### モデルの選び方

| モデル | 目安の速さ（CPU） | 精度 | 使い所 |
|---|---|---|---|
| `tiny` / `base` | とても速い | 粗い | 聞き取りのメモ、非力な PC |
| `small` | 実時間前後 | 実用 | **既定。まずこれ** |
| `medium` | 実時間の 2〜3 倍 | 良い | 会議の記録を後から整える |
| `large-v3` | 遅い（GPU 推奨） | 最良 | 正確さが要るとき |
| `large-v3-turbo` | large より速い | 良い | GPU があるならこれ |

録音中に「変換が追いついていない」と出たら、モデルを 1 段小さくする。

## 保存

- **保存**（`Ctrl+S`）で `txt` / `srt` / `vtt` を選んで書き出す
  - `txt` は**画面の内容そのまま**。誤変換をその場で直してから保存すると、直した方が残る
  - `srt` / `vtt` は**時刻付き**なので、動画の字幕にそのまま使える（保存前の手直しは反映されない）
- **自動保存**は `ドキュメント\文字起こし\` に入る。**保存先を開く**でその場所を開く
- 設定は `%APPDATA%\MojiOkoshi\config.json`、モデルは `%APPDATA%\MojiOkoshi\models\`

## まとめて処理する（画面なし）

```
cli.bat 会議.mp4
cli.bat D:\録音 --model medium --format srt --out D:\字幕
cli.bat 打合せ.m4a --translate          英語にして出す
cli.bat 講演.wav --lang auto --no-time
```

フォルダを指定すると、その中の音声・動画をまとめて処理する。
`cli.bat` にファイルやフォルダを放り込んでもよい。

## うまくいかないとき

| 症状 | 見るところ |
|---|---|
| 入力の一覧に何も出ない | `⟳` を押す。それでも空なら `setup.bat` をもう一度（sounddevice が入っていない） |
| `PC音声: …` を選ぶと開けない | sounddevice が 0.5 未満。`setup.bat` で入れ直す |
| マイクが無音のまま | Windows の **設定 → プライバシーとセキュリティ → マイク** でデスクトップアプリの使用を許可する |
| 文字が出るまで遅い | モデルを小さく（`small`→`base`）、**途中経過**を外す、GPU があれば `処理` を `GPU (CUDA)` に |
| GPU にしても速くならない | `.\setup.ps1 -Gpu` で cuBLAS / cuDNN を入れる。入らなければ CPU のまま使う |
| 「モデルを読み込めなかった」 | 初回はモデルの取得に通信が要る。社内網なら `HTTPS_PROXY` を設定してから `setup.bat` |
| 動画の音声を取り出せない | 珍しい入れ物のとき。`winget install Gyan.FFmpeg` を入れると読めるようになる |
| 起動しない・窓が出ない | `run.bat` の代わりに `cli.bat --help` を実行してエラーを見る |
| 句読点や固有名詞がおかしい | Whisper の癖。`medium` 以上にするか、書き出してから直す |

## 中身

```
transcribe/
  app.py            起動口（画面）
  cli.py            まとめて処理する用
  core/
    audio.py        入力の一覧、マイク / ループバックの取り込み、16kHz への変換
    segmenter.py    無音で発話を切り出す（暗騒音に合わせてしきい値が動く）
    engine.py       faster-whisper の呼び出し、GPU→CPU の退避、ffmpeg での取り出し
    session.py      録音・ファイルの進行役（取り込みと変換を別スレッドで回す）
    formats.py      txt / srt / vtt への書き出し
    config.py       設定の読み書き
  ui/main_window.py 画面
  tests/test_core.py 音の切り出しと書き出しのテスト
```

テストは Windows でなくても動く（音声の入出力に触らない部分だけ）。

```
.venv\Scripts\python.exe tests\test_core.py
```

## 通信について

- **初回のモデル取得だけ** Hugging Face につなぐ。取得後は `%APPDATA%\MojiOkoshi\models\` から読む
- 音声・文字起こしの結果を外へ送ることは無い。クラウドの音声認識は使っていない
