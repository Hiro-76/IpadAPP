# ATIS Grabber（Android）

**毎時 02 分過ぎに LiveATC へ取りに行き、指定した空港の ATIS 音声を自動で保存する**
Android アプリ。端末が寝ていても、アプリを開いていなくても、時刻が来れば録りに行く。

同じリポジトリの iPad 向け PWA とは独立していて、行き来する部分は無い。

---

## 何をしているか

1. アラームを 1 つだけ仕掛けて、次の「毎時 02 分 30 秒」（既定値）に起こしてもらう
2. 起きたら前面サービスを 1 本立てて、選んだフィードの音声を **120 秒（既定値）そのまま録る**
3. 録り終えたら `.mp3` を保存し、古い録音を消し、次のアラームを仕掛け直す

LiveATC が配信しているのは MP3 なので、届いたバイト列をそのままファイルに書いている
（デコードも再エンコードもしない）。ATIS は同じ内容を繰り返し流しているだけなので、
2 分も録れば必ず 1 周ぶん入る。

音声は `https://www.liveatc.net/play/<mount>.pls` を読んで、その中に書かれている
ストリーム URL から取る。`.pls` が読めないときだけ `https://d.liveatc.net/<mount>` を試す。

## 入手する

### GitHub Actions のビルド済み APK を使う（Android Studio 不要）

`android/` 以下を push すると `.github/workflows/android.yml` が走り、
**debug APK が Actions の成果物（artifact）として置かれる**。

1. GitHub のリポジトリ → **Actions** → `Android APK` の最新の実行を開く
2. 下の **Artifacts** から `atis-grabber-debug-apk` をダウンロード
3. zip を展開して端末に移し、`app-debug.apk` を開いてインストール
   （「提供元不明のアプリ」の許可を求められたら許可する）

手動で走らせたいときは Actions の `Android APK` → **Run workflow**。

### 自分でビルドする

Android Studio で `android/` を開いて Run、もしくは:

```
cd android
./gradlew assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest    # 解析まわりの単体テスト
```

必要なもの: JDK 17、Android SDK 35。

## 使い方

1. **ICAO を入れて「検索」**（例 `RJTT` `RJAA` `KJFK`）
   LiveATC の空港ページからフィード一覧を拾い、**ATIS を上に並べて出す**
2. 使うフィードの「選ぶ」を押す
3. 一番上の **「毎時の自動取得」を ON**
4. 「時間どおりに動かすために」の項目を済ませる（下記）
5. 「今すぐ取得」で一度試す。録音が下に増えれば設定完了

フィード名が空欄でも `rjtt_atis` のような **mount 名**で判断できる。
検索でうまく出てこないときは「LiveATC のページを開く」でブラウザに出し、
`/play/○○.pls` や `mount=○○` の `○○` を **「mount 名を直接入れる」** に打てばよい。

### ATIS のフィードが無い空港もある

LiveATC のフィードはボランティア持ち込みなので、**ATIS 単独のフィードが無い空港は珍しくない**。
その場合は Tower や Approach のフィードを選んでおくと、その周波数の交信がそのまま録れる。

## 設定

| 項目 | 既定 | 意味 |
|---|---|---|
| 60 / 30 / 20 / 15 分毎 | 60 分毎 | 1 時間に何回取りに行くか |
| 何分過ぎ | 2 分 | 毎時この分に取りに行く |
| さらに | 30 秒 | 上に足す秒数（既定は毎時 **02:30**） |
| 録音の長さ | 120 秒 | 1 回に録る秒数（30〜300） |
| 保存期間 | 7 日 | これより古い録音は取得のたびに消す（0 で消さない） |
| Wi-Fi のときだけ取得 | OFF | 従量制の回線では見送る |
| アラーム扱いで確実に起こす | ON | 下記 |
| 取得結果を通知 | ON | 取れた / 取れなかったを通知する |

### 「アラーム扱いで確実に起こす」

ON のとき `AlarmManager.setAlarmClock()` を使う。**Doze（省電力の眠り）に遅らされない唯一の種類**で、
Android 12 以降でも追加の許可が要らない。代わりに**ステータスバーに目覚まし時計のアイコンが出る**。
アイコンが邪魔なら OFF にできるが、その場合は
「正確なアラーム」の許可が要る（許可が無いと数分ずれる）。

### 端末の省電力に止められないようにする

「電池の最適化を外す」を押して、このアプリを対象外にしておく。
Xiaomi / OPPO / Huawei などは独自の省電力があるので、
端末の設定でもこのアプリを**「自動起動を許可」「バックグラウンドで制限しない」**にしておく。

## 録音の置き場所

```
Android/data/io.github.hiro76.atisgrabber/files/atis/<mount>/<mount>_20260824_1402Z.mp3
```

**ファイル名の時刻は UTC**（航空の時刻に合わせている）。
アプリ内から再生・共有・削除ができる。共有すれば他のアプリや PC へそのまま渡せる。
アプリをアンインストールすると録音も消える。

---

## うまくいかないとき

| 症状 | 原因と対処 |
|---|---|
| 「音声が届きませんでした」 | そのフィードが停止中。LiveATC のページで生きているか確認する |
| 「音声ではなくページが返りました」 | mount 名が違う。`.pls` のリンクから正しい名前を取り直す |
| 検索してもフィードが出ない | LiveATC 側のページの作りが変わった可能性。ブラウザで開いて mount 名を直接入れる |
| 時刻がずれる / 飛ぶ | 「アラーム扱い」を ON、電池の最適化を外す、端末独自の省電力も見る |
| 通知が出ない | 通知の権限（Android 13 以降）を許可する。取得自体は通知が無くても動く |

## 使うにあたって

LiveATC の音声は**個人で聞くためのもの**で、再配布は認められていない。
このアプリも自分の端末に貯めるだけで、どこにも送らない。
取りに行くのは 1 回の取得につき HTTP 2 本（`.pls` と音声）だけで、
既定では 1 時間に 1 回しか動かない。
LiveATC の音声は実際の交信から **20〜30 秒ほど遅れて**届く。
運航に使う情報は必ず正規の手段（実際の ATIS 受信、ディスパッチ、ACARS）で確認すること。
